## 可直接交给 Agent 的说明

请根据附件生成三个独立的农场动物模型：黑白牛、奶油色绵羊、黄色小鸭。

1. 每个动物一个模型任务；每张 2×2 图集表示同一只动物的四个视角。按四象限裁切成独立图片后，分别将同一动物的视角作为一组多视图参考，不能把三种动物混到同一个模型里。
2. 左上为正面，右上为侧面（头朝左），左下为背面，右下为斜前方。先检查跨视角造型是否一致；有冲突的角度先修正再提交。
3. 保持圆润短肢、大色块、低细节、柔和哑光的玩具感。保持眼睛、耳朵、牛角、蹄子或脚掌的数量正确；腿和翅膀保持可辨认的结构。
4. 牛腹部不要乳房、乳头或其他粉色悬垂部件，严格以 `cow-turnaround.png` 的修订版为准。
5. 背景、阴影与分隔线不建成模型。不要添加毛发、衣服、饰品或额外道具。
6. 输出三个分别命名的 GLB，保留材质。报告每个模型的面数、对象数量及是否含骨骼或动画，并给出正面、侧面、背面的实际模型截图供核对。

生成工具与最终提示词记录见 [GENERATION-PROMPTS.md](./GENERATION-PROMPTS.md)。
