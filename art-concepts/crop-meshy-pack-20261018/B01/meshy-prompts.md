# B01 Meshy 上传提示词

每个作物使用对应独立PNG及下面提示词；这些是成熟态参考图，不是已验收模型。

## 卷心菜

图片：`cabbage-mature.png`

```text
根据参考图生成一株成熟卷心菜，圆润饱满的卡通农场游戏风格。浅黄绿色菜心近球形，由厚实内叶紧密交叠包合，深绿色宽外叶从同一短根冠向外翻卷，高低错落，保留柔和叶脉。准确保持图中轮廓、比例和配色；补全后方叶片，使单株具有前后体积，叶片有厚度，边缘圆钝，连接自然，材质柔和哑光。整株完整、底部居中，适合种植摆放。不要生成土块、地面、花盆、底座、投影实体、文字或悬浮叶片；避免做成散叶生菜、空心菜碗或光滑绿球。
```

## 番茄

图片：`tomato-mature.png`

```text
根据参考图生成一株成熟番茄，圆润饱满的卡通农场游戏风格。粗短绿主茎与枝条自然相连，两颗饱满红番茄各有厚实绿色星形萼片，上方有一朵小黄花。足量阔叶高低错落，叶身厚实、边缘圆钝、叶脉浅柔，保留果实清楚可见。保持图中轮廓、比例和配色，补全背面枝叶，形成前后体积，全部连接同一植株，果梗真实连接果实，柔和哑光。整株完整、底部居中。不要土块、地面、花盆、底座、投影实体、文字、支架或悬浮果实；避免薄片叶子和过长裸茎。
```

## 玉米

图片：`corn-mature.png`

```text
根据参考图生成一株成熟玉米，圆润饱满的卡通农场游戏风格。粗短绿茎上连接一根金黄色饱满玉米穗，颗粒圆钝，沿穗体整齐环绕排列。厚实绿色苞叶包住下半穗并自然剥开，清楚露出上部穗粒；长而宽的绿叶高低错落，向两侧与前后自然弯垂，叶片有厚度和柔和中脉。保持图中比例、轮廓、配色及完整单株，补全背面叶片，连接同一基部，柔和哑光。不要土块、地面、花盆、底座、投影实体、文字或分离穗；避免把穗粒做成平面贴纸、香蕉形或针刺叶。
```
