## 4. 需要实际查看并描述的内容（只描述，不下结论）

1. **天空岛（固定图 overview、pond-east、landscape-back，以及路线截图）**：岛边是否清楚（草地直接断开）；云海、积云、小浮岛是否可见；地平线处天空和云底之间有没有接缝或色差；有没有洋红、黑块、穿帮（看到岛底或地面外缘）。
2. **岛边原生检查**：分别走到东（池塘以东、瀑布小湾附近）、南、西、北四面的墙边，各截一张图。描述：能否看到瀑布或水雾、溪流和池塘岸边接得怎样、露露能否走到溪流上、隐形墙处是否像“撞空气”、岛边暖光带是否可见、灌木和花是否有浮空。
3. **动物走路（录像，至少 60 秒对着牧场）**：腿是否在动、是否像走路而不是平移；脚是否打滑；有没有穿过围栏、谷仓、饲料槽、草垛或彼此重叠；鸭子是否左右摇摆；路线经过牧场时动物有没有挡住露露。
4. **飞鸟**：录像或截图里能否看到，大小是否合适，扇翅是否可见。
5. **O3 淡出 r09**：route 021–024、015/016 与 O6 同名图并排。描述：是否还有整屏规则网格；露露周围是否透明；噪点颗粒是否明显。原生窗口里在主屋背后和树下转一圈（如果鼠标工具仍失败，用键盘 R 回正和走动尽量覆盖，并如实写明）。
6. **光线**：与 O6 同机位比较整体色调（是否偏暖、影子是否变长），只描述。
7. **性能**：附 `performance-table.md`；列出主会话 `wallFrameTimeMs`（mean / p95 / maximum）与 `unscaledDeltaExceedsWallFrames`。
8. **环境声**：如果无法试听，写“未试听”。
9. **采集时的机器状态**：同 O6。
