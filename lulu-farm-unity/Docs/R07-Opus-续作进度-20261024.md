## 本次改动（opus-r07-o6-r01，全部未经 Unity 验证）

1. **新增阶段 `--r07-task O6`**：包含 D6 的全部内容，外加 O3/O5 修订。D5–D6 原复现行为不变（默认仍为 D6）。证据和构建输出到 `Evidence/r07/O6/`、`Builds/r07/O6/`，不会覆盖 DeepSeek 的 D6。两个运行脚本的 choices 已加 O6。
2. **O5 r02**（仅 O6 生效）：S02 放在 `(3.6,0,.35)`，朝向 180，缩放 .8（相当于 worldHeight 2.4）；视觉实例 X 镜像，把筒仓放到东侧；碰撞盒放在未镜像的 holder 上。S09 改到 `(4.0,0,-2.6)`，E15 改到 `(-.4,0,1.0)`，羊回到 `(1,0,-1.5)`。“饲料槽”路线标记从 `(4.3,-2.8)` 改到 `(3.9,-3.5)`，因为旧标记会落进挪过的饲料槽里。sceneRevision 写为 `integration-r07-O6`。
3. **O3 r08 原因（代码层确认）**：
   - 叠层：`FarmOcclusionSetup.MakeFade` 生成的是 URP/Lit 透明材质，ZWrite 关闭，所以房屋和树冠多层壳之间没有深度排序，叠出淡色层。
   - D6 不连续：淡出材质是从 D6 之前的导入材质生成的；`FarmLivingSetupR07` 只替换了 `opaqueMaterials`。树开始淡出时会换成没有风动的 URP/Lit：树冠位移瞬间归零（约 ±0.03m），光照模型也跟着变。
4. **O3 r08 修订**：新增 `LuluFarm/OcclusionDither-r08`，从 LivingSurface-r07 复制，改为 AlphaTest 不透明加 4×4 屏幕抖动，ZWrite 保持开启，阴影保留，`_MotionMode 0` 用于静态房屋。新增 `FarmOcclusionDitherR08.Apply`：在 D6 之后，用渲染器**当前实际使用**的材质生成抖动淡出材质（D6 植物直接复制属性，风动和光照相同），淡出覆盖率设为 .25。`FarmCameraOccluder` 识别抖动材质后改驱动 `_FadeOpacity`；旧透明路径和回归测试保持不变。

5. **O4 修订（第二批，只在 O6 生效）**：
   - 路面碎石改圆点：新 Shader `FarmGround-r04`，只改碎石一行；新材质 `Ground-polish-r04`，复制 r03 的全部参数。
   - 远景地面硬边：新天空材质 `FarmSky-r08`，地平线颜色改为当前雾色 `#C9E0E6`。雾参数仍按 spec C，FarmSky-r01 不改。
   - 动物动作：新 Shader `LivingSurface-r08`，把呼吸和转头幅度改为可设属性；O6 把动物材质设为呼吸 .01、转头 .1rad（D6 为 .003 / .035）。抖动淡出 Shader 也加了同样属性，植物淡出时的动作保持一致。
   - 环境声：鸟鸣 .15、水声 .30。
   - 修订记录写到 `Evidence/r07/O6/opus-r08-revisions.json`。
6. **防止覆盖 DeepSeek 证据**：`FarmLivingSetupR07` 原来把 `ambient-metrics.json` 固定写到 `Evidence/r07/D6`，改为写到当前阶段目录（D6 时结果不变）。Profiler API 清单在 O6 阶段写到 `Evidence/r07/O6`。
7. **录制器修复**：`FarmFrameRecorder.StopRecording` 在已经停止时直接返回，不再改写状态，也不再拉长 `elapsedSeconds`（D7 REPRODUCE.md 点名的问题）。
