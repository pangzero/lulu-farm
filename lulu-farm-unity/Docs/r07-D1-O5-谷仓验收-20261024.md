## 3. O5 判断（DeepSeek 按此修改 Builder，不手改场景）

- **草垛：保留，不切开。** 总图里谷仓周围本来就堆着草垛，草垛和底座连在一起不影响玩法；整体占地是实心碰撞，切开没有收益。
- **尺度：worldHeight 改为 2.4。**（占地约 2.75 × 2.5 m，约占牧场宽度 29%。）
- **位置：挪到牧场的东北角，避开主屋正门。** 牧场范围是 x −3.6…6、z −6.5…1.9。建议 `Place("S02", new Vector3(3.6f,0,.35f), pasture, 180)`。这时占地约为 x 2.2–5.0、z −0.9–1.6，后沿离北侧围栏约 0.3 m，主屋（x≈0）门前视线让开。如果后沿碰到围栏，就把 z 往南挪，每次 0.1 m。
- **朝向和筒仓：门仍朝 −Z，做 X 镜像，让筒仓到东侧。** 要求：
  - 镜像只加在**视觉子物体**上（即带 MeshRenderer 的那一层，localScale.x = −1），**碰撞盒不能挂在负缩放的物体上**（Unity 的 BoxCollider 不支持负缩放）。Footprint 碰撞盒放在未镜像的父物体上，或者单独建一个碰撞物体。
  - 镜像后检查法线贴图光照方向是否正确：房屋和谷仓近景截图，看屋顶瓦片的明暗是否和主光一致。
- **连带移动**：
  - E15（草堆）从 `(4.6,0,.7)` 移到 `(-.4,0,1.0)`（牧场西北角，总图中草垛在左后方）；
  - S09（饲料槽）从 `(4.4,0,-1.9)` 移到 `(4.0,0,-2.6)`，和谷仓前沿留出至少 0.8 m 通道；
  - 羊回到 r06 的 `(1,0,-1.5)`（这个位置已经不在谷仓占地内）。
- **碰撞：保持整块实心盒**，门不可进入，不做室内。
- **淡出**：暂不加入 `FarmOcclusionSetup`。挪到东北角以后，正常游戏机位基本不会被谷仓挡住；O3 做淡出方案时再统一考虑。
