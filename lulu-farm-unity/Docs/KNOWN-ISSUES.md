# 当前候选的已知问题与验收边界

## 已明确保留

- Lulu 使用用户允许临时运动的 locomotion-r08。当前模型被冻结，腰侧接缝、腿顶折带与局部颈部外观没有修复；不标为正式美术通过。控制器与角色外观分离，后续新模型需重新检查骨骼、动作、短裤 FabricUV 和比例。
- 幼苗为 4 个 Meshy 族群原型映射的 14 个派生，只有幼苗、成熟两个阶段，不是 14 个独立原始建模。
- 当前成熟玫瑰使用语义图集局部修订 atlas-semantic-r06／LOD atlas-lod1-r04；旧颜色阈值失败路线仍封存。
- 树与房屋为保持 Lulu 可见而淡出；屋后角度仍可见大面积淡色屋顶／墙面叠层，人物可辨，但不称为完全消除遮挡。
- 主屋檐窗和瓦缝仍有原模型局部折面。场景保持原总图区域关系，远景树线和草地微细节与概念图仍有差异，整场美术等待用户验收。

## 持续测试中的卡顿

M5／1280×720／电脑档／20格全成熟，实际917.684秒中有8个统计窗口含超过100ms的帧，其中3个超过1秒，最大1859.271ms。均值8.393ms、P95 8.367ms不消除这些停顿。原因尚未建立，性能验收保持未通过；具体窗口见 `Evidence/performance-long-frames-r06-20261023.json`。后续使用独立Profiler Timeline定位；当前主线程计数器单位适配不支持TimeNanoseconds、渲染线程计数器不可用，不能写为0ms。

## 资源与平台

- 南瓜成熟态 108,708 三角面、草莓成熟态 429,884 三角面、E16 蓝鱼 126,600 三角面仍是资源例外；当前电脑场景可以测，不能据此称手机最终资源已完成。
- 电脑档的实际运行结论只对应本次 Mac、版本、分辨率与场景密度。手机质量档在 Mac 的切换只验证配置，不代表 Android 真机性能。
- 用户暂不连接 Android 手机，先交电脑包。Android 构建模块此前官方地址被地区重定向后返回 404；本轮无 Android 真机、Windows 或 iOS 实测。
- 包为本地 macOS 开发候选；未做商店上架、Developer ID 公证或跨机分发验收。
- 设备温度没有可用的跨平台测量接口，记录为未测量；帧时间、CPU/GPU 和内存均按实际可用计数器分别标注。

## 历史问题的保留与修复证据

- glTF normal 导入编码错误曾造成大块光照色带：修为非 Lulu 原始 RG 线性纹理；来源与 Lulu payload 不变。
- r04 地面大三角形顶点雾插值产生色带：r05 改逐像素世界位置雾计算，12 张同相机整场图已复核。
- 船内木底原来低于水面 2.295 cm：场景独立抬高 2.9 cm，r05 实际图已确认船内干燥。
- 初版运行包 UI shader 被裁剪：已显式保留 UI/Default，实际中文按钮显示正常。
- r05 快速拖动转镜头曾丢失：r06 使用事件累积。聚焦的真实 Mac 窗口实测 240px 拖动转向 43.2°，UI 起点拖动和暂停阻断通过。Batch Editor 鼠标夹具仍为失败／原因未确认，已停止该测试方法；不将零输入的失败记录改成通过。
