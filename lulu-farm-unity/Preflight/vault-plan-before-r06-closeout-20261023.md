## 3. 所有批次通用的质量标准

### 3.1 先确定造型，再做细节和优化

1. **轮廓与结构**：灰模就能认出种类，主次体块有设计；叶片和果实的连接关系合理。
2. **材质与配色**：与参考和 Lulu 放在一起协调；有克制的明暗与色彩变化，避免塑料强反光、全体同绿和过曝。
3. **使用距离**：近景看得住，缩回农场镜头也能分辨种类和阶段。
4. **GLB 一致性**：网页中的造型、颜色、法线、厚度不能明显劣于原生渲染。
5. **复用与性能**：在已认可造型的基础上整理材质、网格与实例；必要时另做低细节版本。优化后重新比较画面。

增加细分、叶片数量、贴图分辨率或面数，本身都不算质量提升。成熟作物继续采用用户Meshy；幼苗可按本次路线研究结果采用Blender，但必须逐物种控制叶形和叶序，不能套旧通用模板。所有路线都需达到结构和使用距离标准。

### 3.2 明确退回的情况

- 大轮廓仍像球、圆柱、薄片的机械拼装，缺少该物种的结构特征。
- 卷心菜、生菜、小白菜之间主要靠名字或绿色深浅区分；黄瓜和西葫芦换色共用同一形状。
- 叶片正面好看，侧背面却纸片化、消失、出现黑面或不自然的锐边。
- 叶脉像悬浮白线；接缝、分瓣或阴影让果实与叶片像散开的零件。
- 有明显穿帮、漂浮、断开的茎叶、可见穿插；合理的叶片遮叠与种植入土需要区别判断。
- 比旧版圆润一些，但仍明显达不到已确定的参考特征。
- 通过换灯光、改曝光或放大候选来制造提升，无法在共同条件下复现。
- 只有渲染图、只有 `.blend`，或页面仍显示旧 GLB；这些均不能交付为可验收资产。

### 3.3 固定检查条件

B01 建立检查设置，存入 `review/farm-assets/B01/review-settings.json`，后续沿用：

- 近景：正、侧、背、3/4、俯视共五个视角，材质图和中性灰模各一组。重点局部另补特写。模型检查图允许拼成图板，单视图至少 768×768 像素；交给用户上传 Meshy 的参考图始终保持单物种、单视图独立文件。
- 同一种资产的新旧对照共用相机、灯光、曝光、背景、显示比例；先用两版共同的包围范围确定取景，再固定。不同物种可有各自近景构图。
- 灰模移除颜色、纹理和法线细节的干扰，保留真实几何及中性照明，用来检查轮廓、厚度和层次。
- 农场镜头先用 **1280×720、DPR=1、正交 3/4 俯视**建立基准；方位角 45°，相对地面的俯角约 50°。视野展示约 12×8 格田地区域，按整片地取景，不逐株放大。记录最终相机参数和实际画布大小。
- 每类作物再做 3×3 同类种植，检查密度、格线和相邻株遮挡；补 Lulu 只读实例作比例参照。
- 保留 **1.2×1.2 项目单位**的田格约定。B01 测量 Lulu 与现有作物的实际尺寸，确定并记录展示实例的比例；不能修改 Lulu 文件，也不能逐株归一到相同高度。
- 源工程用 Z 向上，GLB 按格式要求转换轴向；网页核对脚底与根部着地。作物原点放根部地面中心，土格和植物独立保存。
- 记录 Blender／网页各自的颜色管理、曝光、灯光与材质设置。两种渲染器不要求逐像素相等，但不能靠网页专用补光隐藏模型或材质缺陷。

### 3.4 技术交付要求

- Blender 制作资产保留合理命名和可编辑分件。Meshy 资产保存导入后的检查／编辑 `.blend`，如原件为合并网格则如实标明，不把它称为手工制作源或承诺原件没有的分件能力。相机、灯光、检查地台不混入生产 GLB。
- 通用 GLB 材质必须实际验证。Blender 专用程序材质如不能可靠导出，则在 Blender 内烘焙为可携带贴图，随后验证真实导出效果。
- 检查并记录顶点、三角面、网格、材质、纹理尺寸、文件体积、包围盒、原点及所用版本；纹理无缺失引用。
- 初期不凭空规定全资产统一的极低面数。B01 记录真实开销；后续在同一设备、画布和场景下测试，再制定各类资产预算。
- 当前机器的帧率不能推断所有手机都能流畅。未测设备写“未测试”；首批不承诺移动端性能。
- 对已有内容先记录路径与哈希。新候选另存，保留旧模型；改动共享页面前备份相关文件，只改本批必需范围。
- 不改 Lulu 与动物原件、不恢复被否决的开放作物、不恢复旧农场／餐厅玩法。

### 10.2 如果直接用Blender，具体怎样做

1. 先锁定每物种的幼株轮廓和拟定世界高度，子叶／真叶、叶数、叶序、根冠分别设计；玉米和小麦不套阔叶双子叶结构。对照成熟只保持叶形和色系，不带成熟器官。
2. 以少量控制点生成叶片中心曲线与横截面，从细叶柄连续过渡到叶面；在曲面里做浅槽、浅中脉和兜形，避免悬浮叶脉线及茎叶拼缝。
3. 给叶面真实厚度，再做克制圆边与必要的低级细分；侧背面检查，不用双面材质遮掩纸片。Solidify用于给网格表面增加厚度，局部缩放会影响厚度，建模时需处理缩放与法线。[Blender Solidify说明](https://docs.blender.org/manual/id/4.5/modeling/modifiers/generate/solidify.html)
4. 首轮以数千到约一万三角面、少量共享材质作评估目标，不能为少面而损失主要轮廓。用柔和基础色、粗糙度及少量可导出色彩变化，不直接依赖不能携带的复杂Blender节点；实际GLB回读验证。[glTF材质导出说明](https://docs.blender.org/manual/es/4.5/addons/import_export/scene_gltf2.html)
5. `.blend`保留可编辑叶片／根冠和修改器，生产导出按材质整理对象；检查相机、灯光与地台不进GLB。根部原点居中、1.2格、三物种不能各自归一到同高。
6. 先看五视图材质／灰模与真实网页，确认自然度和背面，再测试3×3种植与农场镜头；小样达不到概念就定向改造型，不靠加面、换光或批量复制“完成”。正式B08/B09按用户指定范围执行，研究文件不自动晋升。

| 资产 | 方法与理由 | 关键边界 |
|---|---|---|
| S01 中央主屋 | 体块、可控曲面屋顶、倒角、门窗模块；易统一尺寸、正侧背和可编辑结构 | B14 完整外观，与 B02 认可样段区别登记；不开室内。 |
| S02 牧场棚屋 | 挤出／曲线拱顶、墙面和门分件，控制动物通行净空 | 不制作动物和棚内玩法。 |
| S03 农产摊位 | 木构复用、实体篷布厚度与柜台分件；与 S04 共语言并保留用途区别 | 货物独立，不将成熟植株硬塞成离体货物。 |
| S04 渔产摊位 | 同类木构与棚顶，挂架／容器独立 | 鱼货单独引用认可资产，不在摊位里假造新资产。 |
| S05 围栏 | 已认可 r04 模块只读复用；1.2 步长、左柱＋两横档，再加终柱 | 不重复完整双柱造成重叠；必要新角件另存。 |
| S06 牧场门 | 门板、门柱、铰链分件，精确对齐围栏接口，门轴可预留 | 预留门轴不代表已做开关动画。 |
| S07 码头 | 板条与柱模块，控制接岸高程、1.2 格接口与可拼接端 | GLB 为静态模块，无水波。 |
| S08 划艇 | 镜像／曲面船壳、实体厚度、座板与舷缘，方便检查内外侧 | 不含浮力、划桨或驾驶功能。 |
| S09 饲料槽 | 圆角箱体与内腔，槽体和饲料分件，方便动物高度检查 | 饲料体块少量，避免密粒噪点。 |
| S10 路灯 | 柱、支架、灯罩与灯芯分件；实体厚度与材料可控 | 静态灯芯颜色／自发光不等于运行时照亮周围。 |
| S11 木箱 | 模块木板、圆角和钉头，复用材质，确定空箱体积 | 货物单独，空箱本体可先完成。 |
| S12 浇水壶 | 曲面壶身、厚壁口、弧形手柄与壶嘴分件，检查连接和出水孔 | 不包含流水粒子、倒水动画或工具玩法。 |

Meshy 对这些硬模块没有当前必要性：精确接口、薄墙／内腔、重复模块归属、门轴和材质分件都需要明确控制。采用不受控高模后仍要手工清理，并不能消除本项目最重要的拼接工作。

### 10.4 地块与自然环境E类：建议全部Blender

E 类中的树、灌木、花丛和水生植物是**装饰环境资产**，不属于 C01–C16 两阶段可种植作物。植物名称相似不代表可挪用同一模型或需要做幼苗／成熟两套；梨树也不是第 17 种田格作物。全部仍建议 Blender 起步。

| 资产 | 方法与理由 | 依赖／重点 |
|---|---|---|
| E01 空田格 | 复核已有 B03 r03，尺寸与四边接口可测 | 用户确认连铺宽木边；不重造。 |
| E02 幼苗田格 | 组合认可 E01 与独立幼苗实例，不新增专用植物 | 幼苗认可后组装，土和植物始终分离。 |
| E03 草地格 | 精确平面基础、柔和边角和少量草簇 | 对齐 E01、E04、E05，保持平地。 |
| E04 路面格 | 方格接口与少量路面纹理，可控高度 | 连续道路无错层，避免把接缝做成实体裂谷。 |
| E05 水岸直段 | 复核已有 r03，保留实体岸坡与独立岸石 | 接口／水位认可后再扩展岸角。 |
| E06 水岸弯角 | 按 E05 截面推导内外角与必要端件，测闭合接口 | 先列明确变体，封闭池塘无裂缝和露底。 |
| E07 水面格 | 复核已有 r03 静态平面与无缝颜色贴图 | 水位固定；现有不透明材质不显示水下鱼。 |
| E08 圆树 | 设计树冠主副体块与树干连接，控制前后深度 | 圆润但非无设计的球堆，配主屋／Lulu检查比例。 |
| E09 梨树 | 树冠与分枝、梨形果实和果梗独立 | 果有支撑且不过密，非田格成熟作物。 |
| E10 灌木 | 独立设计低矮宽密体块与叶簇，参数少可控 | 不用圆树整体缩小充数。 |
| E11 白花丛 | 少量厚花瓣、叶片曲面与高低错落排布 | 近景有厚度，远景不碎成噪点。 |
| E12 芦苇 | 茎与长叶用可控曲线／实体叶面，穗头按概念轮廓设计 | 稀疏方向变化、避免尖刺密林；不含风摆。 |
| E13 石头组 | 复核已有 r03 圆润变形体块，少量不对称 | 着地、尺度和接触阴影；不重造。 |
| E14 睡莲 | 厚叶片缺口、花瓣和花托分件，与固定水位对齐 | 叶与水面留合理关系，避免共面闪烁；不是 C 类幼苗。 |
| E15 草垛 | 大束形与捆扎带、少量圆钝草束，细方向可用纹理 | 避免数千针状草丝；可沿小麦色系，不复用整株小麦缩放。 |
| E16 简单蓝鱼 | 曲面鱼身、厚鳍尾与眼睛分件，静态造型可控 | 本批无骨骼／游动动画；水下可见需另处理水材质。 |

### 10.5 现在应开始哪些其他任务

以下为路线评估时的排期建议。B03收尾与B14完整主屋现已交付候选、待用户验收，实际状态见5.6；不再重复列为未开始。

**可以开始准备设施环境工作，不必等待两个暂缓作物或全部幼苗做完。**本次只给排期和方法，不自动执行后续批次。
