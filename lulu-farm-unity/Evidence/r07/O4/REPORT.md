## 判断

| 项 | 判断 | 依据 |
|---|---|---|
| 地面与道路（D3） | **基本通过**。牧场门口的直角色块已消失；路沿过渡柔和；道路位置与 r06 一致 | `pasture`、`fields`、`close-house-road`。近景路面上碎石公式 `floor(p*4)` 形成的约 25cm 浅色小方块隐约可见（`close-house-road`），建议下一版改成圆点。 |
| 草地颜色 | **方向正确，略偏暗** | 取样：总图草地色相 71–74°、亮度 .55–.63、饱和度 .57–.67；D6 为 69–77°、.47–.51、.56–.61；r06 牧场为 86°、.51、.50。色相和饱和度比 r06 更接近总图，并不过饱和；差在整体亮度低约 .07。属于小幅曝光或调色调整，不建议改 Shader。 |
| 光照与阴影（D2） | **可接受** | 游戏视角下树影和 Lulu 的影子都清楚，暗部带冷色但不发黑（`route-contact/06`、`close-house-road`）。`close-tree-shadow` 这个机位逆光，看不出树影，不算缺陷。 |
| 白色细节 | **可接受** | 白花、花椰菜、白色筒仓在 `fields`、`pasture` 中都能辨认，没有被冲白；黄色 Lulu 也没有过曝。 |
| 远景地面边界 | **有问题（只在诊断总览机位）** | D6 `overview` 中方形地面的远角和边线在天空前清楚可见；r06 同机位被雾遮住。原因是新雾色较亮、雾距 32–80m，而地面平面不到那么远。游戏视角（如 `pasture`）的地平线正常。属于低优先级；可以把地面延伸到雾终点以外，或让雾终点短于地面边缘。本次未改。 |
| 装饰密度（D4） | **可接受，略稀** | `fields`、`pasture` 的树圈连续；与总图相比，路边的小花和小灌木偏少。没有因此增加实例。 |
| 前景遮挡 | **两处需修，已交 O3/O5** | ① 房屋和树淡出出现半透明叠层：`route-contact/06` 中 `024-…-house-back-360` 半个画面发白、可见多层多边形，`023` 的树冠是浅色圆盘，属于 O3。② 出生点机位右下被谷仓绿屋顶大面积遮住（`spawn`）；牧场机位谷仓挡住主屋一层，羊站在猪背上（`pasture`），属于 O5。 |
| 动态（D6） | **有，但太弱** | 录像中，除 3 处机位切换外，相邻帧差中位数 0.21，无闪烁、无跳帧。运动范围图显示牛头、羊头、猪耳和灌木叶在动，但轮廓位移只有约 1–2 像素（1280 宽画面），正常游戏中几乎察觉不到。蝴蝶很小，只在灌木旁可见轻微变化。水纹和水面动态明显。建议下一版把呼吸 .003 提高到约 .01，转头 .035rad 提高到约 .1rad；本次未改 Shader（需要另存新版本）。 |
| 环境声 | **几乎听不到** | 整段 RMS −57 dBFS，峰值 −35 dBFS；水声底噪约 −70，鸟鸣每 5–8 秒一次，约 −55，能量在 2–6kHz；没有爆音或接缝跳变。O6 阶段已把鸟鸣音量 .045 改为 .15、水声 .12 改为 .30（约 +10/+8 dB）。**我无法试听**，音色和舒适度需要用户本人听。 |
| 整体风格 | **方向接近总图** | 马卡龙配色、圆润造型、区域关系（左田、后屋、中牧场、右池塘）都对。与总图的主要差距：树圈的近景密度、路边小花，以及谷仓位置（O5）。 |
