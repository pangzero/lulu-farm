# D6 动感

状态：**已完成，待 Opus 验收**。

## 做了什么

Builder 调用新增 FarmLivingSetupR07，生成独立动态材质并挂接 FarmAmbientR07。127 个植被实例、5 只动物、4 只蝴蝶、3 处间歇水纹；32 份独立派生材质。原导入网格、纹理和 Lulu 文件不改。来源／派生 SHA256 见 ambient-metrics.json，94 项来源、贴图、派生材质复核无差异，见 material-preservation.json。

- 树冠、灌木、白花和芦苇使用小幅顶点风动；树干下部不动，树冠幅度约 0.025m，灌木 0.012m、花 0.007m。
- 动物脚底锚定，约 0.3% 呼吸变化及偶发约 2° 头颈转动，每只独立相位，同一动物两档 LOD 相位一致；不加入 AI。
- 蝴蝶在花丛附近活动，水纹周期扩散淡出。诊断画面使用现有视角，不增加玩法镜头。
- 画质检查面板增加风动与声音开关；手机档强制关闭风动，切回电脑档恢复用户选择；暂停冻结动态并暂停环境声。
- 鸟鸣与水声为本工程数学合成，无第三方录音；源脚本、两份 WAV、SHA256 与来源声明在 Assets/Farm/Audio/R07/。鸟鸣低音量 2D、水声为池塘附近 3D 音源。
