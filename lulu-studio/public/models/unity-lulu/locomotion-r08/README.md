# Lulu 可替换运动集成候选 r08

当前使用用户指定的 `wardrobe-rig/full-r02` 作为来源。原始 GLB、Blender 源与纹理均未覆盖，SHA256 在 `manifest.json`，回读证明在 `review/unity-integration-20261018/lulu/locomotion-r08`。

用户 2026-10-19 最新指示暂缓 Lulu 模型美术修复，先让角色在农场里运动，之后换新模型。因此本版是允许接入的可替换运动候选；**不是用户美术认可版，也未通过完整角色视觉验收**。r09/r10 腿顶封口没有晋升。

## 接入接口

- 默认：`lulu-game-lod0.glb`，70,082 三角面、8 网格、8 材质、23 骨；同目录 FBX 为 Unity 动画导入桥接。
- 次级候选：`lulu-game-lod1.glb`，37,342 三角面。设备表现需在 Unity 实测。
- 角色世界高度 1.2，缩放 `0.6313689341`；原模型最低 Y 为 `-0.950609`，缩放后向上补根部偏移约 `0.600185`。glTF/Unity 为 Y 上、Z 前。
- `Idle`：3 秒；`Walk`：0.6 秒，匹配世界速度 `0.5471864` 单位/秒；`Run`：0.4 秒，匹配 `1.2777705` 单位/秒。
- 三段均原地循环，Root 不平移。位移由外层控制器负责，播放率跟随实际速度 / 上述参考速度；建议过渡 0.12 秒。不要同时应用根运动。
- Generic 23 骨，或 glTFast Legacy Animation。FBX 导入 clip 名可能带 `Lulu_Modular_Rig|Lulu_Modular_Rig|` 前缀，按末段映射 Idle/Walk/Run。
- Shorts 原配色走 UV0，FabricUV 为 UV1，蓝星和西瓜纹样仅替换 Shorts 材质；原版颜色保留。
- 后续新角色只需保持 Idle/Walk/Run、前向、身高、脚底原点和控制器接口；不用继承本模型的美术缺陷或拓扑。

## 已验证与剩余

源已重新打开，GLB/FBX 已实际重导入；LOD0/LOD1 动作循环端点顶点误差为 0，GLB 包围盒回读误差小于 0.000002。四视角跑步相位、前后灰模、五视图和换装均留有真实渲染。

原组装模型的颈圈接缝、腰侧割痕、后裤暗痕仍保留；前伸脚暴露的腿顶细节在 LOD 上更明显。大面积脚踝压皱已去除，但不能据此宣布所有关节视觉通过。两轮腰侧补片和两轮腿顶封口均失败并停止，没有进入 r08。

本文件不证明 Unity 控制过渡、碰撞、移动端帧率或安装包通过；这些由整合工程分别验收。
