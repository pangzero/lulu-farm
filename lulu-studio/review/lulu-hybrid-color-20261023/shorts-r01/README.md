# Lulu shorts-r01 — 短裤背面扇形折痕修复

2026-10-24。基于 polish-r01（构建前后哈希一致，未改动）。用户决定：新噜噜以 polish-r01 为基础进游戏，先修好短裤背面折痕。状态：候选，等待用户外观验收。预览：`../index.html?rev=shorts-r01`。

## 问题原因

去尾巴时补的背面补片（Shorts 第 2 个图元）是一组从边缘放射出去的细长三角形（最长约 7 cm）。在弯曲表面上，相邻长条的法线插值互相不一致，就形成了扇形折痕；再加上主网格在洞口边缘有一圈尖刺状的三角形，腰带棱线到洞口两侧时中断成两个"夹点"。上一轮只平滑这块补片没有效果，就是因为问题出在三角形排布，不在顶点位置。

## 改动（只动短裤）

1. 删掉补片外层，以及洞口周围 1 cm 内主网格外层的 181 个三角面（主网格只改索引表，顶点不动）。
2. 在新的、更规整的洞口内用均匀网格重新三角化（约 2.3 mm 间距，腰带棱线附近加密），边界与剩余主网格逐边焊接。
3. 表面高度按周围短裤曲面做薄板样条拟合；腰带的台阶棱线按两侧实测（高约 2.5 mm、按世界尺寸）连贯延伸过原缺口。
4. 法线取自拟合曲面；边缘 1 cm 内过渡到主网格原法线（与主网格夹角超过 35° 的上沿除外）。
5. 补片内层（被遮住的衬面）保持原样，仍在新外层之后至少约 4 mm。

其余网格、节点、材质、贴图、头部/眼睛/橘子逐字节一致（见 build.json）。

## 校验（build.json）

- 原缓冲区前缀、节点、材质、原访问器、其余网格、短裤第 3 个图元全部一致。
- 新外层 3619 顶点 / 7124 三角面，全部朝外，无退化面，边缘 112 条全部与主网格单次焊接。
- 在 Mac 上构建的结果和离线生成结果 SHA256 一致。

## 遗留

- 极近距离加侧向检查光时，补片上沿和左侧仍能看到很淡的边界痕迹；正常距离和上色状态下看不出来。
- 短裤侧面靠近手臂处有一条深色细缝，下方还有一条横向浅槽（像原模型的口袋口）。两处都不在这次范围内，也没改动。
- 正面裆部的深色是形体阴影，不是缺陷，没动。
- 没有生成 Blender 副本。
