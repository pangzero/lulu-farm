# Lulu polish-r01 — 明显问题收尾

2026-10-23。基于 eye-r01（用户已认可眼睛），eye-r01、color-r03 等原文件均未改动（构建前后哈希一致）。状态：候选，等待用户外观验收。预览：`index.html?rev=polish-r01`。

## 改动

1. **吻部橙色上沿**：橙色区域上半椭圆高度 0.126 → 0.150。上沿由横直色带变成饱满的弧形，一直延伸到眼睛下方（参考效果），配色和柔边不变。只改了头部顶点色和脸部贴图。
2. **嘴线**：下移约 0.033，半宽 0.080 → 0.088，弧度 0.024 → 0.030，右端略微上翘（参考里嘴角本来就不对称）。只改了贴图。
3. **头顶封口**：原头顶是一块削平的低面数平台，前侧边缘有一圈向下翻折、发暗的面，这就是橘子底部的"浅色接边"。本版把平台改成和周围连续的光滑圆顶：
   - 移动了 5,367 个顶点，拓扑和索引不变。
   - 剩 4 个原本就几乎垂直的细小面，最大面积约 1e-5，而且被橘子盖住。
4. **橘子**：顶点烘焙了新的形状和位置，节点变换不变。
   - 水平收窄 14%，高度拉高 10%，更接近参考的圆扁球。
   - 下沉 0.007，让开口边缘埋进头里。
   - 复杂的叶子收拢成一根短柄的样子（是原叶子收拢变形，不是重建的几何）。

## 校验（build.json）

- 节点、原访问器、其余网格逐字节一致，索引不变。
- 回读核对：头部和橘子的世界坐标与预览数据误差约 1e-7，法线点积 ≥ 0.9999999。
- 截图来自与 GLB 完全一致的数据，使用评审页的相机和灯光设置。这次没有把 62 MB 的文件拉回云端，直接用 GLTFLoader 加载渲染。

## 遗留

- **短裤背面去尾巴留下的扇形折痕**：尝试只平滑那块单独的小补片，但它太窄，没有效果；折痕延伸进了短裤主体网格，需要单独做一次短裤局部修补。
- **正面裆部的深色**：来自形体本身的阴影，灰模里表面是光滑的。如果要更利落，需要改短裤形体。
- 头部侧面体积、颈部、身体比例、耳朵形状没有动（这些涉及已通过的头部或大体型）。
- 没有生成 Blender 副本。

## 兼容版 lulu-colored-portable.glb（给 macOS 预览 / 快速查看 / iPhone AR 用）

macOS 预览、快速查看会把 GLB 转成 USDZ，转换时会丢掉顶点色（COLOR_0），所以身体、短裤、橘子和头部侧后方会显示成白色。`lulu-colored.glb` 本身没有问题，在三维网页预览、Blender、Unity 里都正常。

兼容版用 `tools/make_portable_glb.py` 生成，几何完全不变，只是把顶点色换成了材质和贴图：

- 身体、手臂、腿、短裤本来就是单色（偏差 < 0.005），直接改成材质颜色。
- 橘子拆成橙色和叶子绿两个材质。
- 头部非脸部区域和颈部的渐变，烘焙成一张柱面投影贴图 `body-wrap-basecolor.png`。头部背面接缝处复制了顶点，所以不会出现色带。

看图、发给别人、在苹果设备上查看时用兼容版；继续制作或进引擎时用 `lulu-colored.glb`。
